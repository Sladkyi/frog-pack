# Readable run cycle

frog-run-legs-v1.png generated with built-in ImageGen using frog-armor-0.png as style reference. Original alpha preserved. Eight leg poses in a 4 by 2 atlas: alternating contact, compression, push-off and flight. Requested olive frog legs with dark brown outlines, bright near leg and dark far leg, shared hip anchor, fixed ground, no body/clothes/background/text.

Runtime uses the original armored torso above the legs, with a small forward lean and timed vertical motion. This preserves all five armor appearances. Legs share the same scale and hip registration throughout the 0.52-second cycle.

Bow flight uses only single-arrow columns 0/1. On impact, only columns 3/4/5 are played for 0.36 seconds at the hit position; column 2 (volley artwork) is not part of the animation. Actual multishot projectiles remain separate arrows.
